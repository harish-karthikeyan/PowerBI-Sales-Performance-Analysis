# Sales Performance & Business Intelligence Dashboard

## Project Overview
This Power BI project analyzes sales performance, discount impact, profitability, regional trends, and sales forecasting.

## Features
- Executive Dashboard
- Discount Impact Analysis
- Profitability Analysis
- Regional Performance Analysis
- 20-Day Sales Forecasting
- Business Insights & Recommendations

## Tools Used
- Power BI
- DAX
- Data Modeling
- Forecasting

## Key Metrics
- Total Sales: 118.73M
- Total Profit: 16.89M
- Gross Sales: 127.93M
- Units Sold: 1.13M
- Profit Margin: 14.23%
